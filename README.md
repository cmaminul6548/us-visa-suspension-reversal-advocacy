# Trump Administration Urged to Reverse Immigrant Visa Suspension for 75 Countries

![US Immigration News](https://img.shields.io/badge/Status-Urgent_Update-red)

The Trump administration has recently implemented a sweeping suspension of immigrant visa processing for **75 countries**, including Bangladesh, citing "public charge" concerns. This policy, effective from January 21, 2026, has sparked significant concern among legal experts, advocacy groups, and affected families.
